Agent access

Ten verbs, and none of them write.

An agent can read a company, its canonical fields with their provenance, the filings a figure came from, a thesis scored, exposure through your book, what a recompile would propose, the seven Red Team seats and what hedging a fall would cost — and it can draft or check a plan for you to approve. The same rights, point-in-time and audit checks apply whichever door the caller comes through.

Excel and Google Sheets, today

From the Workspace tab in the desktop terminal:

  • Connect Excel generates a VBA module. Import it into Microsoft Excel once, and formulas in your workbook call Quantify Terminal directly.
  • Google Sheets copies an Apps Script connector. Paste it under Extensions › Apps Script, and formulas in the sheet do the same.
  • The built-in Workspace spreadsheet runs the same formulas inside the terminal, with CSV, JSON and XLSX import and export.

The formula is the same everywhere:

=QT("AAPL","price")

The module and the script are generated for you, with the formulas and the connector address already in them. Pointing them at your own Quantify connector is two fields in the Workspace panel — its URL and the key it accepts — and the terminal writes both into every module it generates after that. The connector itself is yours: you deploy it once, from the folder the terminal hands you, and the desk that deployed it holds the key.

Two things worth knowing before you plan around it. The Workspace spreadsheet inside the terminal answers these formulas with nothing deployed and no key — a deployment is only needed to reach them from Excel or Sheets. And the connector returns market data and portfolio figures, not the canonical fields with provenance that the verbs above return; for those, the door is MCP.

MCP and Python

An MCP server exposes ten verbs over stdio, so an assistant can call the terminal as a tool. A Python client calls the same server, so a notebook and an agent get the same answers. There is no HTTP API for any of this today — the one HTTP service we run carries model calls so that no desktop is handed a provider key, and it serves no Quantify data — and we would rather say so than let you plan around one.

The server is set up on request rather than shipped in the download: it runs against a checkout and the terminal's own environment, and we configure it with you. Write to us and we will send the configuration.

The ten verbs

Eight read. Four of those read your own account — your theses, your committed models, your book — and answer “not yet” rather than inventing something when no account is signed in.

  • resolve_company — a ticker, ISIN or name to one canonical id, with the identifiers and the fields known for it.
  • get_facts — canonical fields with the source, the period, and when each first became knowable. A figure another source reports differently carries the disagreement; one that does not look like the same source’s own history carries that too.
  • get_evidence — that company’s filings, most material first, each with the stored sentence and its offsets so a quote can be checked rather than trusted.
  • thesis_health — a thesis scored, with every assumption’s status, never a number without its breakdown.
  • look_through_exposure — the routes from a company to what you hold, each step named.
  • model_diff — what a recompile would propose against your committed model, cell by cell, with the sentence behind each change.
  • red_team — the seven seats, each arguing from one evidence path, or naming what it could not read and taking no side.
  • hedge_architect — what protecting a position against a fall you name would cost: puts, proxies and selling down, on cost, carry, coverage and basis risk.
  • propose_plan and review_plan — a plan made only of steps this build declares, each marked with the permission it needs and whether it can run without a person. Neither executes one.

What an agent cannot do

  • Write anything. Every verb is a read; nothing is saved, refreshed or spent.
  • Place an order. Nothing here prepares one, let alone sends it.
  • See data the caller is not licensed to see. A value from a source that may be shown on your screen but not placed in someone else’s prompt is withheld — named and counted, never silently dropped, so the assistant can tell you a number exists and cannot be shared. See how we handle data rights.
  • Read the past on a plan that does not include point-in-time. An as of read is refused with the same sentence the desktop shows.
  • Act without an audit row. Every rights decision is recorded with the account that asked and the call it belonged to, allowed or refused, with the reason.
