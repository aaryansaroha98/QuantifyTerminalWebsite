# what-changed-today/ is generated

Everything in this folder except this file is written by `tools/publish_brief.py --site` in the
desktop repository (Quantify Terminal), one page and one JSON file per morning plus an archive
index, an index fragment and `rss.xml`. Each generated file carries the mark
`generated by tools/publish_brief.py`; the publisher refuses to overwrite a file here that does
not, so nothing written by hand in this folder is ever replaced, and it never writes outside it.

* `/what-changed-today` is still `what-changed-today.html` at the root, which the publisher does
  not touch. There is deliberately no `index.html` directly in this folder, so the clean URL keeps
  serving the hand-written page.
* `tools/build-sitemap.py` exits on any `.html` file that is neither listed nor excluded. Before
  the first brief is published it has to learn `what-changed-today/briefs/`.
* How the pipeline is hosted, and what is still to switch on: `docs/BRIEF_PUBLISHING.md` in the
  desktop repository.
