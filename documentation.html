Structure

Five layers keep the terminal coherent.

Layer 01

Command and navigation shell

The top shell gives users direct symbol entry, status visibility, alert access, regional context, currency context, ticker movement, and fast tab navigation.

Layer 02

Shared market context

Market snapshots, symbol updates, movers, indices, watchlist changes, portfolio symbols, broker snapshots, and news refreshes can flow into the places that need them.

Layer 03

Panel workspace model

Panelized tabs let users clone, detach, collapse, link, export, print, and reset views. This gives desktop-grade flexibility without turning every page into a separate app.

Layer 04

Local persistence and account controls

Window state, tab labels, layouts, workspace notes, trade logs, preferences, user context, and update settings are designed to remain stable between sessions.

Layer 05

Release and distribution readiness

The project already supports native desktop build paths for Windows, macOS, and Linux, with release metadata ready to power update and download workflows.

Workflow example

From symbol to decision context.

A user can start from the command bar or a watchlist, inspect the dashboard and chart context, open research and filings, compare peers, check portfolio exposure, review headlines, set an alert, and log the decision in the workspace.

  1. 01Search or select a symbol.
  2. 02Review market snapshot and chart context.
  3. 03Move into valuation, ratios, ownership, filings, and peers.
  4. 04Check portfolio exposure, watchlist state, and alert rules.
  5. 05Export, journal, or prepare the next action.
