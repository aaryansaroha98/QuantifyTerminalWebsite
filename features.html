Panel ergonomics

Built for dense screens without losing control.

The product uses a panel-first workspace model. Users can detach panels into windows, duplicate panels, resize columns, link symbol context, export panel data, save views, collapse panels, and reset layouts when a workflow gets too complex.

This matters because professional market work rarely happens in a single table. A chart, screener result, news item, portfolio exposure, and research panel often need to sit together.

MoveRearrange panels by column and priority.
DetachOpen important views in a separate window.
LinkKeep related panels following the same symbol.
ExportMove table output into reports or review files.
CloneCreate alternate views without rebuilding context.
